# Goodwlsdn.github.io

개발 공부 기록을 쌓기 위한 개인 블로그입니다.

## 방향

- 만든 프로젝트를 하나씩 정리
- Python 자동화, 데이터 수집, 데이터 분석 기록
- GitHub Pages 또는 별도 호스팅으로 공개 가능한 블로그

## 프로젝트

- [주소 검색 · 지오코딩 API](projects/seoul-address-search-api/README.md) — FastAPI, SQLite FTS, GeoJSON 기반 주소 검색 API

## Prerequisites

- Node.js `>=22.13.0`
- pnpm

## Quick Start

```bash
pnpm install
pnpm run dev
pnpm run build
```
